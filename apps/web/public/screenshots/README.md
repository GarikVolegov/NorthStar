# 📸 PWA Screenshots — NorthStar

Questa cartella contiene gli screenshot usati nel manifest PWA
per la scheda di installazione su Android/Chrome.

## File richiesti

| File | Dimensione | Form factor | Descrizione |
|------|-----------|-------------|-------------|
| `mobile-home.png` | 390×844px | narrow (mobile) | Home page su iPhone 12 |

## Come catturarli

1. Apri l'app in Chrome DevTools con device iPhone 12 (390×844).
2. Naviga sulla home page.
3. `Cmd+Shift+P` → "Capture screenshot"
4. Salva come `mobile-home.png` in questa cartella.

> Gli screenshot sono opzionali ma migliorano l'esperienza di
> installazione su Android mostrando un'anteprima dell'app.
