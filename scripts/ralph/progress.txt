- READ FIRST each iteration: memoria.md (root) + the relevant *_RULES.md for the area you touch (API_RULES.md, DB_RULES.md, FRONTEND_RULES.md, AI_RULES.md). memoria.md §10 changelog has the latest state.
- GATE (pnpm is NOT on PATH here): `export PATH="$HOME/.local/bin:$PATH"` first. Typecheck server: `cd apps/server && node --max-old-space-size=4096 ../../node_modules/typescript/bin/tsc --noEmit`. Lint: from repo root `./node_modules/.bin/eslint <files> --max-warnings=0` (do NOT prefix with `node`). - ROUTES: server routers mounted in apps/server/src/route-config.ts (import + entry with auth 'public'|'authenticated'|'admin'); web pages in apps/web/src/route-config.ts (guard 'public'|'protected', lazy import). A router mounted 'public' can still protect sub-paths with an internal guard (see /api/contact and /api/affiliazione: `router.use('/leads', requireAdminAccess)`).
