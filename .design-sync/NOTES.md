# design-sync NOTES (NorthStar)

Repo-specific gotchas for syncing the NorthStar UI library to claude.ai/design.
Read this before any re-sync.

## Shape & layout
- **Package shape**, but the DS is NOT a standalone built library — the ~60 shadcn/ui
  (new-york) components live inside the `@northstar/web` app at
  `apps/web/src/components/ui/*.tsx`. There is no library `dist/`.
- We bundle via an **explicit barrel** (`apps/web/.ds-barrel.ts`, auto-generated) passed
  as `--entry`. The converter walks up from it to `apps/web/package.json`, so `PKG_DIR`
  resolves to `apps/web` with no node_modules self-symlink (pnpm doesn't create one for
  `@northstar/web`). Component list is pinned via `cfg.componentSrcMap` (60 entries) —
  `--entry` mode disables src auto-discovery, so the map is the source of truth.
- `--node-modules` must be **`apps/web/node_modules`** (where react/radix/etc resolve via
  pnpm symlinks). Repo-root node_modules is sparse (no top-level react).
- `@/` alias resolves because the converter's tsconfig-paths plugin reads
  `apps/web/tsconfig.json` `paths` directly (baseUrl defaults to `.`). `cfg.tsconfig` =
  `tsconfig.json` (apps/web-relative).

## Regenerating build inputs (run before re-sync if the component set changed)
- Barrel + componentSrcMap are generated by `.design-sync/.cache/gen-inputs.mjs` +
  `gen-config.mjs`. If you add/remove a UI component, edit the `map` in `gen-inputs.mjs`
  and re-run both, then re-merge (the map is the only thing that needs hand-editing).
- **Compiled CSS:** `cfg.cssEntry` = `apps/web/.ds-compiled.css`, a copy of the production
  Tailwind v4 build output (`apps/web/dist/public/assets/index-*.css`). It is fully
  self-contained: all utility classes + the Deep Navy Premium theme tokens (light+dark).
  Regenerate with `cfg.buildCmd`:
  `apps/web/node_modules/.bin/vite build --config apps/web/vite.config.ts && cp apps/web/dist/public/assets/index-*.css apps/web/.ds-compiled.css`
  (pnpm is NOT on PATH in this env — invoke the vite binary directly; node lives at
  `/Users/gazz/.local/bin/node`).

## Excluded components (5) — intentional, not misses
- `UpgradeGate` — app-coupled (`@/hooks/useSubscription`, `wouter`).
- `tts-button` (`TTSButton`) — app-coupled (`@/hooks/useTTS`).
- `toaster.tsx` (`Toaster`) and `sonner.tsx` (`Toaster`) — both export `Toaster`
  (`export *` star-export collision → undefined on the global) AND render empty
  statically (runtime notification containers). The toast primitive is carded via
  `Toast` (from `toast.tsx`) instead.
- `sidebar-menu-extensions.tsx` — sub-parts of `Sidebar`, not standalone components.

## Grouping
- All 60 components currently emit `group: "general"` — they're flat in `src/components/ui`
  with no sub-dirs, and `--entry` mode derives group from the src path only. If nicer DS-pane
  grouping is wanted later, add per-component `@category` JSDoc or a docsMap stub map.

## Re-sync risks (watch-list)
- **CSS staleness:** `.ds-compiled.css` is a committed snapshot of a production build. If UI
  components start using utility classes not present app-wide at snapshot time, those cards
  render unstyled until you rerun `cfg.buildCmd`. When in doubt, rebuild.
- **Bundle size:** the barrel pulls radix + framer-motion + recharts + embla + cmdk + vaul +
  react-day-picker + react-hook-form into `_ds_bundle.js`. Expected; it's the real shipped code.
- **Target project is shared/hand-authored:** the Claude Design project
  `b3849797-072a-4ae5-9021-9cd74ad8129b` ("NorthStar Design System") was built interactively
  and contains hand-authored `ui_kits/`, `preview/`, `assets/`. This sync runs the **atomic
  path with empty deletes** — it ADDS the `components/**` tree but OVERWRITES root
  `_ds_bundle.js` and `README.md`. Do not add the hand-authored paths to the delete plan.

## Render-loop findings (first sync)
- **HoverCard → floor card (deliberate).** Hover-only Radix popper; its content collapses/clips in static headless capture (positioning transform vs entrance animation conflict). Left unauthored = honest floor card. Component is fully importable. Re-attempt later if a static composition is found.
- **Toast / Sheet** authored with inline `transform:none; opacity:1` (+ static ToastViewport) to defeat the Radix entrance animation that otherwise leaves them blank/sliver in static capture.
- **AspectRatio** uses inline `style={{width}}` (not `w-[Npx]`): arbitrary Tailwind values used ONLY in previews are NOT in the compiled cssEntry (Tailwind scanned `apps/web/src`, not `.design-sync/previews/`), so the ratio box collapsed. Prefer inline styles for arbitrary dimensions in previews; default-scale utilities are all present.
- **ChartContainer** uses a literal `fill="hsl(43 44% 44%)"` (the gold `--primary`) — recharts didn't resolve `var(--color-value)` from the chart config in static capture (rendered black).
- **Avatar** authored with AvatarFallback only — external `AvatarImage` URLs (github.com/*.png) are unreliable in headless and rendered as a broken oversized image.
- **Known benign:** ContextMenu shows only its right-click trigger area (no static open state); Carousel shows the first slide. Both acceptable.
